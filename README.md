Boss fight game for computer science by Kevin, Raymond, and Arnav
## Overview
The player (a student) gets shrunk down and ends up in their computer science class. The player now has to fight an evil computer from their computer science class. The player can fire projectiles to harm the enemy. The game has several stages. Each time the player defeats one stage, the game moves on to the next. Each stage entails a new power/ability for the enemy. Defeating this boss lets the player access the shrink machine and return to their original size.
